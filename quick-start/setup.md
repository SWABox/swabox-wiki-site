# 下载与安装

---
本章节将指引您下载并安装SWABox。

# 检查系统配置

---
> [!TIP]
> 在您要在要运行 SWABox 的设备上安装 SWABox 前，都应该按照这部分的指引检查系统配置是否符合应用的需求。

要运行 SWABox，您的系统必须满足以下要求：

* __Windows__: Windows 10 及以上版本的系统，x86_64 或 arm64 架构

> [!IMPORTANT]
> 该应用目前仅支持 Windows 操作系统。
> 欢迎各位贡献者为该应用测试并添加对其他操作系统的支持。

所以，我们需要先检查系统配置。根据您使用的操作系统，按照以下步骤查看系统配置信息：

### 首先，我们要打开系统信息界面。

:point_right: __按下 `Win` + `R` 打开【运行】窗口，输入以下命令，然后按下回车：__
```bash
control /name Microsoft.System
```

运行完命令后，系统应该会打开以下的一个界面，我们要重点关注划红圈的部分：
![win10](/win10Sys.png)

![win11](/win11Sys.png)

> [!TIP]
> 这里的win10系统信息借用的是ClassIsland文档中的图片
> 
> [原文档](https://docs.classisland.tech/get-started/setup.html#%E6%A3%80%E6%9F%A5%E7%B3%BB%E7%BB%9F%E9%85%8D%E7%BD%AE)

:point_right: __检查显示的系统要求是否符合 SWABox 运行所需的要求。__
如果其中的“系统版本”所显示的系统版本大于或等于 Windows 10，那么您可以在此设备上运行 ClassIsland。

在“系统类型”中显示的是当前设备的架构和安装的系统类型。 __“64 位操作系统”即代表您的操作系统是 x64 架构，“适用于 ARM 的 64 位操作系统”即代表您的操作系统是 arm64 架构。__

:point_right: __记住此处显示的设备架构和系统类型。__

# 下载 SWABox

:point_right: __在浏览器中打开https://swabox.cc.cd/ 下载 SWABox。__

此时您应该能看到如下页面：
![swabox](/swabox-site.png)

:point_right: __点击导航栏中的“下载”按钮，自动下滑至如下区域:__
![download-swabox](/swabox-st-DL.png)

:point_right: __点击“下载”按钮，开始下载 SWABox。__

::: tip
本网站提供的下载服务是通过github API实现的，大陆用户若下载速度过慢，请使用加速器或下载工具下载。
:::

此时，您的浏览器应该会自动下载 SWABox。
